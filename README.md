# Product Dashboard - Frontend Internship Assignment

## Project Overview
A responsive product dashboard built with React that fetches and displays products from FakeStore API with search, filter, sorting, and favorites functionality.

## Features Implemented

### Core Requirements
- ✅ Product Grid Display
- ✅ Search by Title
- ✅ Filter by Category
- ✅ Sort by Price (Low to High / High to Low)
- ✅ Responsive Design (Desktop, Tablet, Mobile)
- ✅ Product Detail Modal

### Bonus Features
- ✅ Dark/Light Theme Toggle
- ✅ Favorites with localStorage
- ✅ Loading Skeleton
- ✅ Error Handling
- ✅ Component-based Architecture
- ✅ React Hooks (useState, useEffect)

## Tech Stack
- React.js
- CSS3 (Flexbox & Grid)
- JavaScript (ES6+)
- FakeStore API

## How to Use
1. Browse products in the grid
2. Use search bar to find products
3. Filter by category from dropdown
4. Sort products by price
5. Click product card to view details
6. Click heart icon to add to favorites
7. Toggle theme using moon/sun icon
